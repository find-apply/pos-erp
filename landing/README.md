# landing — صفحة عرض خدمة DzERP

صفحة تعريفية ثابتة (HTML/CSS/JS فقط، بدون أي مكتبة أو بناء) تقدّم خدمة **DzERP**:
نظام ERP و POS متكامل للمؤسسات الجزائرية، بالعربية واتجاه RTL وبالدينار الجزائري.

## التشغيل

الصفحة ثابتة، يكفي فتحها مباشرة:

```bash
open landing/index.html
```

أو عبر خادم محلي (مستحسن حتى تعمل الخطوط والصور كما في الإنتاج):

```bash
cd landing && python3 -m http.server 4173
# ثم http://127.0.0.1:4173
```

## الشعار

الشعار مأخوذ من شعار التطبيق نفسه `main-file/public/brand/dzerp-logo.png` (الذي يستعمله
`resources/js/components/application-logo.tsx`)، بعد إزالة الخلفية البيضاء وقصّه:

| الملف | الاستعمال |
| --- | --- |
| `assets/img/dzerp-mark.png` | الرمز وحده 256×256، في الترويسة والتذييل و favicon |
| `assets/img/dzerp-logo.png` | الشعار الكامل بالكتابة 760×245، في `og:image` |

الرمز يوضع فوق بلاطة بيضاء بزوايا مستديرة، لأن جسمه كحلي داكن ويختفي فوق الخلفيات الداكنة.
إن تغيّر شعار الشركة، أعد توليد الملفين من المصدر الجديد بنفس الطريقة (خلفية شفافة + قصّ).

## اللغات (AR ⇄ FR)

الصفحة ثنائية اللغة: عربية RTL افتراضيا، وفرنسية LTR عبر المبدّل `ع | FR` في الترويسة.

- **ترتيب اختيار اللغة**: `?lang=fr` في الرابط ← الاختيار المحفوظ في `localStorage` ← لغة المتصفح.
- رابط مباشر للنسخة الفرنسية: `index.html?lang=fr`
- التبديل يغيّر `lang` و `dir` على `<html>`، ويقلب اتجاه الأسهم والشريط المتحرك وشريط التقدّم،
  ويحدّث `<title>` و `meta description`.
- **العربية تعيش في `index.html` مباشرة**، و `assets/js/i18n.js` يحمل الفرنسية فقط:
  كل عنصر يحمل `data-i18n="مفتاح"` (أو `data-i18n-aria` / `data-i18n-ph` / `data-i18n-alt`)،
  والنص العربي الأصلي يُلتقط عند التحميل ويُستعاد عند الرجوع للعربية.
- **لإضافة نص جديد**: ضع النص العربي في HTML مع `data-i18n="مفتاح.جديد"`، وأضف نفس المفتاح
  في كائن `FR` داخل `i18n.js`. المفتاح غير المترجم يبقى بالعربية بدل أن يختفي.

## Version française

La page est bilingue : arabe RTL par défaut, français LTR via le sélecteur `ع | FR` de l'en-tête.
Lien direct : `index.html?lang=fr`. Le contenu arabe vit dans le HTML, le français dans
`assets/js/i18n.js` — pour ajouter une chaîne, ajoutez `data-i18n="cle"` dans le HTML puis la meme
cle dans l'objet `FR`.

## التفاعلات

- وضع ليلي/نهاري يُحفظ في `localStorage` ويتبع تفضيل النظام أول مرة.
- شريط تقدّم التمرير أعلى الصفحة، وتحديد الرابط النشط في القائمة.
- ظهور تدريجي متسلسل للعناصر، وعدّاد أرقام، وتوهّج يتبع المؤشر على بطاقات «لماذا».
- شريط إجراء ثابت في الهاتف + زر العودة للأعلى.
- كل الحركات تتوقف تلقائيا مع `prefers-reduced-motion`.

## ملاحظات قبل النشر

- **معلومات التواصل مؤقتة**: `contact@dzerp.dz` و `+213 000 00 00 00` والعنوان — تُعدَّل في `index.html`
  (قسم `#contact` والتذييل).
- **نموذج الطلب لا يرسل شيئا**: التحقق يتم في المتصفح فقط ويعرض رسالة نجاح. للربط الحقيقي
  عدّل معالج `submit` في `assets/js/main.js` ليرسل إلى نقطة API أو خدمة نماذج.
- **الأرقام في القسم العلوي** (`+30` وحدة، `DZD`، `RTL`، `24/7`) مأخوذة من قدرات النظام الفعلية،
  ولا توجد أي أرقام عملاء أو شهادات مُختلقة.
- **وسوم `og:` تبقى بالعربية** لأن روبوتات المشاركة لا تنفّذ الجافاسكريبت. إن كانت النسخة الفرنسية
  مهمة للـ SEO، أنشئ صفحة `fr/index.html` ثابتة بدل الاعتماد على المبدّل وحده.
- الخطان `IBM Plex Sans Arabic` و `Cairo` يُحمَّلان من Google Fonts؛ للعمل دون إنترنت استضِفهما محليا وعدّل `<link>`.
